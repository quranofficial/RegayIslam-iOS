## 🚀 چۆن ئەپەکە بنیاد بنێم (Build)؟

### هەنگاوی ١ — Flutter دابمەزرێنە
ئەگەر Flutter ـت نییە: لە [docs.flutter.dev](https://docs.flutter.dev/get-started/install) دایبەزێنە،
پاشان لە تێرمیناڵ:

```bash
flutter doctor
```

### هەنگاوی ٢ — فۆڵدەری پرۆژەکە بکەوە و platform ـەکان دروست بکە

```bash
cd regayislam
flutter create --org com.nwezhakanm --project-name regayislam --platforms android .
```

> ⚠️ ئەم فەرمانە هەموو شتێک دەهێڵێتەوە و تەنها `android/`، `ios/` و پێویستییەکان دروست دەکات.

### هەنگاوی ٣ — دەستپێکی Android Manifest

فایلی `android/app/src/main/AndroidManifest.xml` بکەوە و لەناو `<manifest>` ئەمانە زیاد بکە:

```xml
<uses-permission android:name="android.permission.INTERNET"/>
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE"/>
<uses-permission android:name="android.permission.VIBRATE"/>
<uses-permission android:name="android.permission.WAKE_LOCK"/>
<uses-permission android:name="android.permission.POST_NOTIFICATIONS"/>
<uses-permission android:name="android.permission.SCHEDULE_EXACT_ALARM"/>
<uses-permission android:name="android.permission.RECEIVE_BOOT_COMPLETED"/>
```

لەناو `<activity>` ـی سەرەکی (MainActivity) `android:exported="true"` دڵنیابە.

### هەنگاوی ٤ — جێبەجێکردن

```bash
flutter pub get
flutter run

flutter build apk --release
```

ئەگەر minSdk کێشەی هەبوو، لە `android/app/build.gradle` بیکە: `minSdk = 21`

- **Splash** — ئامادەکاری داتابەیس + ئاگادارکردنەوەکان

- **Home** — بەنەری ڕەمەزان (Firebase)، پەخشی ڕاستەوخۆ، تەسبیح، کاتەکانی بانگی شار، ٣٦ کارتی تایبەتمەندی
- **قورئان**: لیستی سوورەت + گەڕان، خوێندنەوە بە ١٠ تەفسیر، دەنگی قورئان بە قارئەکان، ئایەتی ڕۆژ، ناوەکانی خودا (٤ زمان)
- **نوێژ**: هەب (٢٠ کارت)، خشتەی مانگانە، ڕێکخستنی بانگ، دواخستن/پێشخستنی کاتی بانگ، دوعاکانی نوێژ + ١٤ سکرێنی خوێندنەوە (فاتیحە، جەژن، بانگ، تەیەمموم، دەست نوێژ، بەتاڵکردنەوەی نوێژ...)
- **ڕوقیەی شەرعی** — لیستی ١٧ دەنگی ڕوقیە (taybat.json) + لێدەر بە SeekBar و داگرتنی ئۆفلاین (RuqyayActivity + RockActivity)
- **پوختەی سەحیحی موسلیم** — کتێبی فەرموودە لەسەر mu.db: ٦٩ بەش + ٢٠٠٩ فەرموودە، دڵخواز/کۆپی/هاوبەشی (FarmudaActivity + PwxtaActivity)
- **چۆن تەوبە بکەم؟** — کتێبی گەڕانەوە لەسەر garanawa.db (٥ خشتە) (PageActivity)
- **ئافرەتان** — هەبی ٣ بەش: چل فەرموودە، پرسیار و وەڵام، باڵاپۆشی (QuestionActivity)
- **قیبلەنما** — قەپۆز ڕاستەقینە + بەرنامەسازکردنی گۆشەی قیبلە
- **تەسبیح** — لیست + ژمێرەر لەرینەوەدار
- **میدیا** — ڤیدیۆکان (Firebase: تاگەکان، پۆستکردنی ڤیدیۆ، سەرنجەکان) + **پەخشی ڕاستەوخۆ لەناو ئەپەکە** (کەناڵەکانی مەککە/مەدینە بە HLS لەگەڵ video_player)
- **پرسیار و وەڵام (Quiz)** — لە Firebase وەردەگیرێت، ڕەنگی سەوز/سوور وەک ڕەسەنەکە
- **ڕەمەزان** — بەشەکان لە rm.db + بەنەری Firebase
- **کتێبخانە** — ١٠٢ کتێبی PDF لە ktebakan.json (وێنەی بەرگ، کورتە، نوسەر، داگرتن و خوێندنەوەی ئۆفلاین) + خوێنەری PDF (MeoActivity + BookActivity)
- **ڕێکخستن** — دۆخی شەو/ڕووناکی، فۆنتەکان، پەیوەندییەکان (فەیسبووک/تێلێگرام/تیکتاک)
- **پەیام و ڕەخنە + پرۆفایل** — دەنێردرێت بۆ Firebase

## ✅ هەماهەنگاندن لەگەڵ پڕۆژە ڕەسەنەکەی Android (RegayIslam v70.1)

ئەمانە زیادکراون بۆ ئەوەی هەموو شتێکی ئەپی Android ی ڕەسەن لەم وشانەشدا هەبێت:

- **ڕوقیەی شەرعی** — لیستی دەنگەکان (taybat.json) لەگەڵ لێدەری تەواو (پەخش، SeekBar، داگرتنی ئۆفلاین، دڵخواز)
- **پوختەی سەحیحی موسلیم** — خوێنەری کتێبی mu.db لە ناو «فەرموودەکان» هەبەکەوە
- **چۆن تەوبە بکەم؟** — خوێنەری garanawa.db (کارتەکەی ماڵ پێشتر فایلی هەڵەی دەکردەوە)
- **ئافرەتان** — هەبی ٣ بەش (gggg.json، girlss.json، balaposhi.json)
- **بەتاڵکردنەوەی نوێژ** — کارتەکەی نوێ لە هەبی نوێژ (NwezhiActivity)
- **دواخستن و پێشخستنی کاتی بانگدان** — سلایدەری ±٦٠ خولەک بۆ هەر بانگێک (BrdnapeshActivity)؛ گۆڕانکارییەکان ڕاستەوخۆ لە خشتەی ئاگادارکردنەوەکان جێبەجێ دەکرێن
- **دەنگی سوورەتەکانی قورئان** — mushaf و ئایەتی ڕۆژ بە قاری هەڵبژێردراو دەخوێنرێنەوە (بە شێوەی بنەڕەت سعد الغامدي وەک SplashActivity) و هەڵبژاردنی قاری لە «دەنگەکان» یان لە ڕێکخستنی قورئان هەموو ئەپەکە دەگۆڕێت + نیشاندانی تۆخی ئایەت بەپێی داتابەیسی کاتی هەر قاری (QariakanActivity + OpenquranActivity). پەخش ناتوانێت؛ ئەگەر ستریمینگ سەرکەوتوو نەبوو دەنگەکە خۆکارانە داگیراوە و لە فایلەوە لێدەدرێت، و دانەی داگیراو بە ئۆفلاین دووبارە لێدەدرێتەوە
- **هەڵبژاردنی دەنگی بانگبێژ** — لیستی دەنگەکانی بانگ لە dangebangbezh.json بە گەڕان، داگرتنی دەنگ پێش لێدان (بە ئۆفلاین دووبارە لێدەدرێتەوە)، دوگمەی «تاقیکردنەوەی بانگدان» (KtebActivity)
- **دەنگی زیکرەکان** — زیکری لەخەو هەستان، بەیانیان، ئێواران و خەوتن دەنگی تایبەتی خۆیان هەیە (Hack1Activity)
- **ڤیدیۆی ئاینی** — ١٣٦+ ڤیدیۆی mp4 لە videoNew (نێستکراو: فۆڵدەر > ڤیدیۆ)، تاگەکان لە videoall، لێدەری ڤیدیۆ لەناو ئەپەکە (video_player) بە SeekBar، ژمارەی لایک/سەرنج/کات، ناردنی ڤیدیۆ بۆ feedbackvideo بۆ پێداچوونەوە، و سەرنجەکان بۆ هەر ڤیدیۆیەک (ListvideokanActivity + PlayvideoActivity)
- **کتێبخانە** — ١٠٢ کتێبی PDF لە ktebakan.json بە وێنەی بەرگ، کورتە و نوسەر؛ **گەڕان لە کتێبەکان**، **داگرتن بۆ ئۆفلاین بە پێشکەوتنی ڕێژەیی**، فلتەری «دابگیراوەکان» و کردنەوەی ئۆفلاین؛ لینکی پانەگەی دڵ URL-encode کرا (MeoActivity + BookActivity + PdfActivity)
- ناوەکانی هەبی نوێژ بە ڕەسەنەکەوە یەکخران (شەونوێژ، چونە سەرئاو، مانای نوێژ، نوێژی چێشتەنگاو) و سکرێنی «کاتی دەستکردی نوێژ» کە لە ڕەسەنەکەدا نەبوو لابرا

## ⚠️ جیاوازییەکان لەگەڵ ڕەسەنەکە

1. **ویجێتی سەر ماڵەوە (Home Widget)** — لە Flutter ناتوانرێت بە پاکێجی ئاسایی دروست بکرێت؛ پێویستی بە `home_widget` + کۆدی ڕەسەنی Kotlin هەیە. ئەگەر ویستت دەیکەم زیاد بکەم.
2. **FCM (پەیامی ناو ڕاستەوخۆ)** — ڕەسەنەکە Firebase Messaging ی بەکارهێناوە؛ لێرە ئاگادارکردنەوە خۆماڵییەکان بەکاردێن (پێویستی بە هیچ ئاکاونتێک نییە). ئەگەر FCM ـت ویست، `firebase_messaging` زیاد بکە و `google-services.json` دابنێ.
3. **دەنگی نوێژ** — کاتەکان لە داتابەیسی `time2.db` (٣٦٦ ڕۆژ × ٣٤ شار) دێن — هەمان داتای ڕەسەنەکە. دەنگی هەڵبژێردراوی بانگبێژ لەناو ئەپەکە بەکاردێت (بیستن و تاقیکردنەوە)؛ ئاگەدارکردنەوەی سیستەم (لە دەرەوەی ئەپ) دەنگی بنەڕەتی ناو پاکێجەکە لێدەدەت چونکە Android/iOS ڕێگە نادەن دەنگی داگیراو لە نۆتیفیکەیشن بەکاربهێنرێت.
4. **کتێبەکانی کتێبخانە** — لە GitHub ـەوە دێن (`quranofficial/ktebakan`)؛ بۆ ئۆفلاین کۆپیەکی بنەڕەت لە `assets/data/ktebakan.json` هەیە و دوا لیستی داگیراو لە بیرگەی ئەپەکە کاش دەکرێت.

## 🍎 دروستکردنی Unsigned IPA بە GitHub Actions

فایلی `.github/workflows/ios-ipa.yml` لە macOS Runner ـدا ئەپەکە Build دەکات بەبێ Code Signing و ئەنجامەکە وەک Artifact پاشەکەوت دەکات.

### چۆنیەتی بەکارهێنان

1. ئەم فۆڵدەرەی پرۆژەکە Upload بکە بۆ GitHub Repository ـێکی تایبەتی (Private) یان گشتی.
2. لە GitHub → Actions، Workflow ـی **Build RegayIslam Unsigned iOS IPA** هەڵبژێرە.
3. **Run workflow** دابگرە.
4. کاتێک Build تەواو بوو، لە بەشی Artifacts، `RegayIslam-unsigned-IPA` دابەزێنە.

### گرنگ

- ئەم IPA ـە **Unsigned** ـە؛ واتە بێ Certificate و Provisioning Profile دروست دەکرێت.
- IPA ـی Unsigned بە شێوەی ئاسایی ڕاستەوخۆ لە iPhone دامەزرێنرێت نا. بۆ دامەزراندن پێویستە بە شێوەیەکی دروست Sign ـی بکرێتەوە.
- لەم workflow ـەدا هیچ Apple Developer Account یان GitHub Secret ـی Signing پێویست نییە.
- ئەم workflow ـە لە GitHub Actions جێبەجێ دەبێت؛ لەسەر ئەم ژینگەیەی گفتوگۆ Xcode/macOS بەردەست نییە، بۆیە IPA تا Run ـکردنی workflow دروست نابێت.

## 🆕 نوێکردنەوەی ئەم وشانە (Update)

هەموو ٢٣ داواکارییەکە جێبەجێ کران:

1. **بەشی دەنگ لە خوارەوە** — سیستەمی edge-to-edge ڕێکخراوە؛ بارێ دەنگ (AudioPlayerBar) بەسەر دوگمەکانی ناڤی مۆبایلدا دیارە.
2. **دەنگی مەزبووت** — `AudioSetup` بۆ هەموو لێدەرەکان: AudioFocus + media stream + volume 100% لەسەر Android و iPhone.
3. **قارئ + ئایەت + مەشەف** — کاتی خوێندنەوە (timings) بەپێی قارئی هەڵبژێردراو بار دەکرێت؛ قورئان بە شێوەی **پارە (جوزئی ١–٣٠)** ـیش دەکرێتەوە.
4. **Widget** — ویجێتی کاتەکانی بانگ + ویجێتی قورئان (دەق و ڕێکەوت).
5. **ئایەتی ڕۆژ لە Widget** — هەر ڕۆژێک بە خۆکار ئایەتێکی نوێ دەنێردرێت بۆ ویجێتەکە (لە Splash).
6. **ئایەتی ڕۆژ** — «سوڕەتی» تەنها یەک جار دەنووسرێت، گەورە/بچووککردنی تەنها بۆ ئایەت (پاشەکەوت دەکرێت)، تەفسیر + دڵخواز + هاوبەشی.
7. **بەشی دڵخوازەکان** — لەیئاوتە نوێیەکە کێشەی overflow نایەت و هەموو جۆرە بابەتێک بە دروستی دەکرێتەوە.
8. **دەستکاری بەشەکان** — لە «ڕێکخستنی بەشەکان» هەر بەشێک دەتوانرێت بگۆڕدرێت (ناوی نوێ + گەڕانەوە بۆ ناوی ئەسلی).
9. **ناڤیگەیشنی خوارەوە** — لیستەکان پادینگی سیستەمی خوارەوە وەردەگرن؛ دوگمەکان هیچ کاتێک بەربلاو نەبوون.
10. **ناوەکان بە کوردی سۆرانی** — هەموو ناوەکان کوردین.
11. **سەیڤی وێنە** — خشتەی مانگانەی نوێژ بە یەک دوگمە وەک وێنە کاتێکرێتە گەلەری (gal).
12. **بانگبێژ بە ئۆفلاین** — دوگمەی «داگرتنی هەموو دەنگەکان»؛ پاش داگرتن بێ ئینتەرنێت کاردەکات.
13. **گزشتـن → گزنک** — ناوی نوێژەکە چاک کرایەوە.
14. **دۆخی شەو بە کۆمڵەیی** — دیالۆگ، SnackBar، BottomSheet، AppBar، Switch و ستاتوس بار هەموو بە دۆخی شەو جێبەجێ دەبن.
15. **ئیدیتی قورئان + دروستکەر** — دروستکردنی وێنە و ڤیدیۆ لەناو ئەپ (QuranCreatorScreen) و پاشەکەوتکردنیان بۆ گەلەری.
16. **ئایەتی کورسی** — دەنگی تەواو + داگرتنی ئۆفلاین + سیکبار.
17. **لایک و سەرنج** — لایک بۆ هەر مۆبایلێک یەک جار (پاشەکەوت دەکرێت)، ژمێرەری سەرنج ئەپدەیت دەبێت، دڵخوازی ڤیدیۆ ڕاستەوخۆ دەکەوێتە بەشی ڤیدیۆ.
18. **داگرتنی هەموو سوورەتەکان** — بۆ هەر قارئێک، بە پرۆگرێس و هەڵوەشاندنەوە.
19. **سیکباری دەنگ** — بار و کاتی دەستپێک/کۆتایی لە هەموو لێدەرەکان.
20. **هاوکاتکردنی دەنگ و ئایەت** — هاشتایمی قارئەکان ئایەتەکە ڕەنگ دەکات و خۆکار سکرۆڵ دەکات؛ «سوڕەتی» دووبارە نایەتەوە.
21. **دوگمەی هاوبەشی** لە هەموو بەشە سەرەکییەکاندا لەگەڵ لینکی ئەپ.
22. **پانێلی بەڕێوەبەر** — لە ڕێکخستن (وشەی نهێنی لە `kAdminPassword`): ئاگادارکردنەوە، دیالۆگ، ڤیدیۆ و تاگ، بارکردنی فایل بۆ GitHub، و دەستکاری Firebase. هەروەها `admin/admin-panel.html` ـیش ئامرازی ئاگادارکردنەوەی پێ زیادکرا.
23. **APK + وێبسایت بە خۆکاری ٢٤/٧** — GitHub Actions: هەر push ـێک APK دروست دەکات (Artifacts) و وێبسایت بۆ GitHub Pages بڵاو دەکاتەوە. IPA ـی unsigned ـیش بە دستی Run دەکرێت.
